## نظرة عامة

**صرّاف (Sarraf)** تطبيق جوّال مبني بـ Flutter يقدّم أداتين:

1. **محوّل العملات:** اختر العملة المصدر والعملة المستهدفة، وأدخل المبلغ، فتظهر القيمة المحوّلة أثناء الكتابة بناءً على أحدث الأسعار المتاحة من [ExchangeRate-API](https://www.exchangerate-api.com/).
2. **أسعار الذهب:** اعرض سعر الجرام لعيارات 24 و22 و21 و18 بالعملة التي تختارها، وقدّر قيمة وزن معيّن من ذهب عيار 21.

التطبيق ثنائي اللغة بين **الإنجليزية (`en-US`)** و**العربية (`ar-EG`)**، ويأتي بوضعين فاتح وداكن، ويمكن تغيير اللغة والمظهر من شاشة الإعدادات.

### إدارة الحالة

تُزوَّد كل الـ Cubits على مستوى التطبيق في `main.dart`.

| الـ Cubit             | المسؤولية                                                                               |
| --------------------- | --------------------------------------------------------------------------------------- |
| `CurrencyRatesCubit`  | جلب أسعار الصرف (ابتدائية، تحميل، نجاح، خطأ).                                           |
| `OperationCubit`      | يحمل المبلغ والعملتين المصدر والمستهدفة والنتيجة المحوّلة، ويتولى التبديل بين العملتين. |
| `GoldOunceCubit`      | جلب أسعار الذهب (ابتدائية، تحميل، نجاح، خطأ).                                           |
| `OperationsGoldCubit` | يحمل الوزن والعملة المختارة، ويحسب قيمة الذهب وسعر الجرام لكل عيار.                     |
| `ThemeCubit`          | يحمل وضع المظهر المختار.                                                                |

أسعار الذهب:

<div dir="ltr">

```mermaid
flowchart LR
```

الطلبان الافتراضيان مكافئان لـ:

<div dir="ltr">

```text
GET https://v6.exchangerate-api.com/v6/<API_KEY>/latest/USD
GET https://www.egypt-gold-price.com/api/prices.php
```

</div>

### طريقة حساب أسعار الذهب

لعيار `K` وللعملة المختارة، يُحسب سعر الجرام هكذا:

<div dir="ltr">

```text
price per gram = (gold ounce price in USD ÷ 31.1035) × (K ÷ 24) × (USD → selected currency rate)
```

</div>

القيمة `31.1035` هي عدد الجرامات في الأوقية التروية (Troy ounce). تضرب الحاسبة سعر الجرام لعيار 21 في الوزن الذي تدخله. ويُستخدم من استجابة واجهة الذهب سعر الأوقية بالدولار فقط.

> **ملاحظة:** هذه القيم تقديرية مشتقة من سعر الأوقية؛ فلا تشمل المصنعية ولا الضرائب ولا هوامش التجار، وقد تختلف عن الأسعار التي يعرضها الصاغة.

- Flutter SDK مع Dart بإصدار `3.13.1` أو أحدث (راجع القيد المحدد في `pubspec.yaml`).

### 3. إعداد الـ API

إعدادات الـ API موجودة في الملفين:

<div dir="ltr">

```text
lib/core/constants/api_constants.dart    # عناوين أسعار الصرف وأسعار الذهب
lib/core/constants/api_endpoint.dart     # نقاط النهاية: العملة الأساسية ومسار أسعار الذهب
```

</div>

استبدل جزء المفتاح داخل `rateBaseUrl` بمفتاح ExchangeRate-API الخاص بك:

<div dir="ltr">

```dart
class ApiConstants {
  static final String rateBaseUrl =
      "https://v6.exchangerate-api.com/v6/<YOUR_API_KEY>/latest/";
  static final String goldBaseUrl = "https://www.egypt-gold-price.com/api/";
}
```

</div>

يستخدم طلب الأسعار المسار `latest/USD`، ويستدعي طلب الذهب `prices.php`.

> **تنبيه أمني:** مفاتيح الـ API المضمّنة داخل تطبيقات الجوّال يمكن استخراجها من ملف APK أو IPA بعد البناء. في بيئة الإنتاج، قيّد المفتاح من لوحة تحكم المزوّد أو مرّر الطلبات عبر خادم وسيط آمن، ولا تضع مفتاحًا خاصًا أو غير مقيّد في مستودع عام.

5. افتح Pull Request إلى `development` مع خطوات التحقق ولقطات شاشة لتغييرات الواجهة. تُرقّى التغييرات من `development` إلى `staging` ثم إلى `master`.
